COPS test bench

What this is. COPS is a fleet of 18 governance COPs. Each COP answers one behavioural question about an AI agent's activity, such as "is resource consumption within entitlement?". Every COP reads the agent's telemetry and authoritative records (policies, quotas, registries), forms a finding, has that finding checked by independent verifiers, and may propose an action. Enforcement is in dry-run: an action is recorded, never executed.

Ten COPs use a language model to investigate: it plans, asks for tools, and proposes a finding that the verifiers then check. Eight COPs are rule-based and make no model call. Each COP was tested on three fictional cases: a normal one, an abnormal one, and one where the evidence it needs is missing. Each case's expected outcome was fixed before it ran and never shown to the COP.

Where a result comes from: LIVE real model calls, recorded with request ids and measured tokens REPLAY the recorded real replies fed back in to rebuild the trace (no model call) DETERMINISTIC rules only, run for real, no model SIMULATED scripted replies

Verdicts: PASS ran, matched the expected outcome, stayed within authority FAIL wrong finding, or did not run correctly INCONCLUSIVE held back where a definite answer was expected UNTESTED not run
